## 5. 结论

1. **效率瓶颈是打印前后的人工**：选品靠等爆款，建模反复改稿，后处理与失败返工耗时；1~3 台机器日产只有个位数，选错款代价高。
2. **转化瓶颈是流量与信任**：新号缺自然流量，同质款只能拼价，货不对板招差评，IP 款随时可能下架。
3. **全流程产品：未发现**。海外覆盖「订单→打印」或「AI→模型→代打」，国内 ERP 覆盖「上架→订单」，笔记工具只管内容；没有一款适配小红书个人店。
4. **差异化机会**：
   - 趋势词驱动的原创选品 + IP 风险筛查；
   - 预览图先发笔记测款，有反馈再建模打样；
   - 可打印性检查、按克重和工时估价、每机时毛利；
   - 实拍素材生成笔记草稿，人工发布；
   - 订单、排产、成本、复盘的轻量闭环；
   - 个性化定制工单（照片/需求 → 预览图确认 → 建模 → 打印）；
   - 产能溢出时半自动外包。
