这一版新增**成本定价器**：侧栏多了一个一级入口「定价」，每个单品上架之前就知道——**卖多少钱、赚多少、一天最多接多少单**。它不调用任何 AI 接口，不需要密钥。

## 新增：定价

侧栏顺序现在是 调研 → 图片 → 建模 → **定价**。页面三栏：左边选项目，中间填成本参数，右边是结果——**改任何一个数，右边立刻重算**；停手约半秒自动保存。

- **成本拆解，逐行对得上账**：
  - 材料 = 克数 ×（1 + 损耗率）× 耗材单价 ÷ 一次成功率
  - 电费 + 折旧 = 打印小时 ÷ 一次成功率 ×（平均功率 × 电价 + 机器购入价 ÷ 预期寿命）
  - 人工 =（后处理 + 打包 分钟）× 每分钟工钱；再加包装和运费补贴
  - **失败的打印不只浪费耗材，也占着机器**：所以一次成功率同时摊到材料和机时上。
- **三档建议价**：按目标毛利率（默认 50% / 60% / 65%，可改）反推，**只往上**取到 x5.9 / x9.9（百元以上取 x9）——所以实际毛利率一定不低于目标。点一档就定价，也可以自己填。
- **你定的这个价下的账**：毛利率、每件毛利、**每机时毛利**（机器是个人卖家的瓶颈——打印时间长的单品要有更高的单件毛利才值得占机器）。
- **三条提醒，都不拦你**：毛利率不到 50%；每机时毛利低于底线（默认 ¥5 / 小时，可改）；售价高于或低于调研到的**竞品价格带**（价格带来自这个项目的调研；图上能看到三档价和你定的价落在哪）。亏本价单独提示。
- **产能**：一天能交付几件（已扣掉失败的）、48 小时内最多发几件——小红书的现货要求 48 小时内发货，接单超过这个数就该挂预售；以及机器全开时这个单品一天的毛利上限。
- **克数和时长从哪来**：照切片软件的数填；项目名下有建好的模型时，可以「按名下模型估算」（体积法，几个零件就合计）；打过样之后，**「用最近一次成功打样的实际值」一键带入**——它比任何估算都准。
- **打样记录**：每打一次记一笔——成功 / 失败、实际克数和时长（旁边显示当时的预估，之后看得出估得准不准）。**失败必须写原因**：失败率是成本的一部分，失败原因是改设计的依据。记满 3 次后会给出你的实际成功率，可一键采用。
- **打印机 · 耗材 · 默认值**（定价页右上角）：打印机档案（平均功率、购入价、预期寿命、出料速度、成型空间）、耗材档案（单价、密度）、这个资料库的成本默认值（电价、人工、包装、运费补贴、损耗、成功率、渠道、三档目标毛利、每机时毛利底线）。
  - 在成本模型里选一份档案 = 把它的数**带进来**，之后还可以在这个项目里单独改。以后改档案、改默认值，**不会悄悄改掉已经定好价的项目**。
  - 一份档案都不建也能用：有一套出厂假设（256 mm 立方、100 W、¥3000、5000 小时；PLA ¥70 / 公斤）。
- **渠道费率预设**：小红书模玩 / 家居饰品 / 文创手作 5%、个性定制 / DIY 2%；闲鱼 0.6%；微信小店 2%（1%~5% 视类目）；自定义。都能直接改——这是 2026-09 核对的数，平台说变就变，以你卖家后台看到的为准。

## 变化

- **项目的「打样」阶段从此有清单**：有一次**成功**的打样记录 + 在定价器里定了售价。两样都有，看板卡片显示「可推进」，进入「上架」不用写原因；缺哪样，推进时的对话框会列出来。项目中枢在这个阶段的按钮是「打样与定价」，并多了一栏摘要（单位成本 / 售价 / 打样成功数）。「上架」及之后的阶段还没有工具，清单仍然是空的、靠你自己判断。
- 「毛利率 ≥ 50%」**不是**阶段门，只是提醒——有的引流款就是故意定低价。

## 修复

- 关闭对话框或切换页面时，如果光标正停在某个输入框里（定价页的数字框、图片页和建模页的重命名框），应用内部可能报错。已修复。

## 已知问题

- 「按名下模型估算」用的是体积法（2 圈壁 + 15% 填充），只是个量级；支撑、裙边、不同的切片设置都会让实际值不一样——打过一次之后请用实际值。
- 耗材库存只是记一笔，还不会随打印自动扣减；打样记录还不能带照片。
- 还不会调本机的切片软件来精确估算克数和时长。
- 真实的 AI 接口（DeepSeek、MiniMax、通义千问）仍未用密钥实测过；这一版的定价器与它们无关。
- 没有自动更新，新版本需要重新下载安装包。
