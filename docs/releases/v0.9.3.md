这一版做两件事：**把调研、图片、建模三个工作台接到「项目」这条主线上**——项目走到哪一步、每一步产出了什么，现在都在项目上看得见，也由它驱动下一步；以及 **AI 的回复改成流式，一轮跑到一半可以停**。

## 下载哪个

| 系统 | 文件 |
|------|------|
| Windows 10 / 11（64 位） | `PrintPilot_0.9.3_windows_x64-setup.exe` |
| macOS 11+，Apple 芯片（M1 及以后） | `PrintPilot_0.9.3_macos_apple-silicon.dmg` |
| macOS 11+，Intel | `PrintPilot_0.9.3_macos_intel.dmg` |

`SHA256SUMS.txt` 是三个文件的校验值。安装包还没有做代码签名：Windows 上 SmartScreen 提示「未知发布者」时点「更多信息 → 仍要运行」；macOS 上第一次要在「访达」里右键应用 →「打开」（macOS 15 起在「系统设置 → 隐私与安全性」里点「仍要打开」）。

从旧版升级：直接装新的安装包即可。这一版**没有改数据库结构**；建模引擎的版本没变，不会重新解一遍。

## 新增：项目是主线

- **阶段清单是算出来的，不用手工打勾。** 每个阶段「离开之前该有什么」，从项目名下的产出里看：
  - 灵感 → 写下了要验证的假设
  - 调研 → 有一份调研报告
  - 概念 → **采用**了一张预览图（光出图不算）
  - 建模 → 建出了一个模型（光有设计不算）
  - 打样、上架、运营、复盘的工具还没做出来：清单是空的，界面明说「先靠你自己判断」，不会假装完成。
- **点看板上的卡片，打开的是「项目中枢」**：阶段条 → 这个阶段的清单 + 该去哪个工作台的按钮 + 「进入下一阶段」→ 名下的调研 / 图片 / 模型（点开就回到对应的工作台）→ 基本信息 → 阶段流转记录。到现在花了多少 AI 费用显示在顶上。
- **从项目里发起调研 / 出图 / 建模**：产出直接挂在这个项目名下；跳过去时输入框里已经有一句由项目名称、品类、假设拼出来的草稿（可以改，不会自动发送）。「建模」会优先拿已经采用的那张图当参考图。
- **三个工作台里都有「打开项目」按钮**（画板 / 设计 / 调研挂了项目时出现）：项目中枢直接盖在当前页面上，不用离开工作台。
- **「调研」成了侧栏一级入口**（原来「灵感池」的位置），排在「图片」「建模」前面——按一个单品走过的顺序。有了**历史**（做过的调研都在，点开就是当时的报告）；可以选「为哪个项目调研」，也可以不挂项目，先找机会、看到好的再「采用为项目」。「预研」页只剩 3D 模型工具。
- **看板卡片上看得见产出**：调研 / 图 / 模型的数量；当前阶段的清单完成时，右下角显示「✓ 可推进」。

## 变化

- **什么时候要写「跳过原因」，现在看证据，不看跨了几格。**
  - 以前：往前跳过至少一个阶段才问。
  - 现在：路过的阶段里有清单没完成就问（哪怕只走一步），对话框里会**列出到底缺什么**；证据齐了，一次跨两个阶段也不用解释；往回拖（返工）永远不问。整个跳过一个还没有工具的阶段（比如从「建模」直接到「上架」）要写原因，顺着走出这样的阶段不用。
  - 这条规则后端也会再判一次。

## 新增：流式回复与「停止」

- **建模对话的回复一个字一个字地出来**：思考模式下先看到思考内容的最后一小段；AI 的那句话到了就显示在气泡里；写到代码时只显示「正在写代码 · 已写 N 行」（对话栏很窄，几百行代码刷过去没有意义；写完后照旧可以在代码编辑器里看）。自动修复时每一版重新计数。
- **建模对话、出图、调研都可以中途「停止」**：
  - 正在等 AI 的请求会被断开，建模引擎里正在跑的脚本约 0.1 秒内停下（以前只能等 90 秒超时）。
  - 被停掉的这一轮**什么都不保存**，输入框里的话原样留着，改一改可以再发。
  - 提示是一句普通的「已停止」，不是红色的报错。
- 需要知道的：**已经生成的内容，供应商照样计费**——停止省下的是还没生成的那部分。出图请求一旦发出去，那几张图多半已经在画了。被停掉的那一轮花了多少我们算不出来（用量在回复的最后才给），所以不记进项目的花费里。
- 演示模式下 AI 的回答也是逐段出现的，不填密钥也能体验流式和「停止」。

## 用之前

- 真实使用需要你自己的密钥（「设置 → 接口密钥」）：DeepSeek 是必需的；出图另需 MiniMax 或通义千问。
- **真实接口仍未用密钥实测过**（包括这一版新加的 DeepSeek 流式输出；解析是按官方格式写的，并有单测覆盖被切碎的数据块）。如果流式显示异常或报错，把提示里的原文发回来。

## 已知问题

- 出图规划、出设计规格、看图复核、调研这几类回复不是流式的（它们是结构化数据，半截没法给人看），但都可以「停止」。
- 项目中枢还是一个加宽的抽屉；完整的项目详情页等打样、上架这几个阶段有东西可放时再做。
- 还不能在工作台的列表里按项目筛选。
- 没有自动更新，新版本需要重新下载安装包。
