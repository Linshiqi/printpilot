这一版两件事：**自己的图可以导入了**——选文件、直接拖进窗口、或者粘贴，导入的图和生成的图一样可以接着改、采用、送去建模；以及**设置页改成了二级菜单**，不用再在一长页里往下滚。

## 下载哪个

| 系统 | 文件 |
|------|------|
| Windows 10 / 11（64 位） | `PrintPilot_0.9.8_windows_x64-setup.exe` |
| macOS 11+，Apple 芯片（M1 及以后） | `PrintPilot_0.9.8_macos_apple-silicon.dmg` |
| macOS 11+，Intel | `PrintPilot_0.9.8_macos_intel.dmg` |

`SHA256SUMS.txt` 是各个文件的校验值。安装包还没有做代码签名：Windows 上 SmartScreen 提示「未知发布者」时点「更多信息 → 仍要运行」；macOS 上第一次要在「访达」里右键应用 →「打开」（macOS 15 起在「系统设置 → 隐私与安全性」里点「仍要打开」）。

如果这个页面上还有 `…-update.exe` / `….app.tar.gz` / `latest.json`：那是给应用内升级用的，不用手动下载。

从旧版升级：直接装新的安装包即可。数据库没有变化（仍是 v6）；建模引擎的版本没变，不会重新解一遍。

## 新增：导入自己的图

以前「图片」里的图只能靠 AI 生成。现在你手里的图——样品的实拍、手画的草图、找来的参考——都可以放进画板：

- **导入图片**：没图时在大图区中间，有图之后是胶片条最前面的那一格；可以一次选多张。大图周围空白处的右键菜单里也有。
- **直接拖进窗口**：拖到画板这边 = 导入成画板上的图；拖到右边的对话栏 = 只贴到这句话上当参考图。悬着的时候两边各有一个虚线框告诉你松手之后会发生什么。一个画板都没有时，会自动新建一个。
- **粘贴（`Ctrl+V`）**：截图、浏览器里「复制图片」、资源管理器里复制的图片文件都行。光标在对话输入框里时，粘贴的图当这句话的参考图；在别处就是导入。

导入的图和生成的图**同等地位**：可以选中、采用、导出、送去建模，也可以让 AI 接着改（比如对一张实拍说「把背景换成纯白」）。胶片条上导入的图右下角有一个小标记；它**不算 AI 生成**——发布包里的「AI 生成」标记只跟着真正由模型画出来的图（包括从导入的图改出来的）。

入库时会做几件事：

- 按照片里记录的方向摆正，并**去掉照片里的元数据**（手机照片里有拍摄地点和机型，而这张图之后会发给模型、会发到平台上）。
- 最长边超过 4096 像素的缩到 4096。
- 真有透明的图（抠好的产品图）保留为 PNG，其余存为 JPG。
- 支持 PNG / JPG / JFIF / WebP，一次最多 20 张。**HEIC、AVIF 不支持**，请先另存为 JPG。
- 一批里有坏图或不支持的文件时，能导入的照常导入，导不进来的逐个告诉你文件名和原因。

「送去建模」时，大图和带透明的 PNG 会先另做一张缩小的参考图再交给模型，不会把几 MB 的原片直接发出去。

**拖放顺手接到了另外两处**：

- **建模**：把图拖进来 = 参考图。还没打开设计的话会新建一个——从一张图开始建模，拖进来就行。
- **上架**：把图拖进来 = 这个项目的实拍图。「导入实拍图」按钮也改成了可以多选。

## 变化：设置页改成二级菜单

左边一列菜单，右边一次只显示一组：**通用**（外观、语言、演示模式）· **接口密钥** · **图片生成** · **资料库** · **关于与更新**。每一组在最小的窗口里也不用滚动。

- 「接口密钥」旁边显示已经配了几个；有新版本时「关于与更新」旁边有一个小点。
- 图片工作台里的「还没配密钥 · 去设置」现在直接落到「接口密钥」这一组。
- 上次停在哪一组会记住。

## 已知问题

- **拖放是用模拟的系统事件验证的**：真的从资源管理器里拖一个文件进来这一步，以及 macOS 上的拖放和粘贴，还没有验证过。松手的位置（落在画板 / 落在对话栏）如果判得不对，请反馈。
- 从浏览器里直接把网页上的图拖进来不行（那不是一个本地文件）——请在网页上「复制图片」，回来按 `Ctrl+V`。
- 在线升级还没有被真实地跑过一次（需要先配置签名密钥和下载地址）；macOS 上的升级未验证。
- 真实的 AI 接口（DeepSeek、MiniMax、通义千问）仍未用密钥实测过。
