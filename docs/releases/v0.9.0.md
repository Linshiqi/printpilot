PrintPilot 的第一个可安装版本：给 3D 打印个人卖家的桌面工作台。**一个安装包，装完即用**——不需要另外安装 Python、数据库或任何运行库，数据全部留在本机。

## 下载哪个

| 系统 | 文件 |
|------|------|
| Windows 10 / 11（64 位） | `PrintPilot_0.9.0_windows_x64-setup.exe` |
| macOS 11+，Apple 芯片（M1 及以后） | `PrintPilot_0.9.0_macos_apple-silicon.dmg` |
| macOS 11+，Intel | `PrintPilot_0.9.0_macos_intel.dmg` |

`SHA256SUMS.txt` 是三个文件的校验值。

**首次打开的提示（安装包还没有做代码签名）**

- Windows：SmartScreen 提示「未知发布者」时，点「更多信息 → 仍要运行」。安装不需要管理员权限。
- macOS：第一次要在「访达」里右键应用 →「打开」；macOS 15 起在「系统设置 → 隐私与安全性」里点「仍要打开」。

## 这一版有什么

- **看图 → 代码建模（build123d）**：参考图 + 文字要求 → 设计规格（先给你审、给你改）→ 写建模脚本 → 本机引擎执行 → 自动检查，不合格就带着真实报错自己修。产物是尺寸精确的 B-rep，可导出 **STEP / STL / 3MF**。
- **局部修改**：参数面板改数字即重建（约 0.2 秒，不调用模型、不花钱）；一句话指令只改相关的特征段，可以先在 3D 视图里点选位置；「看图复核」把 4 个视角的渲染图和参考图比对，每条差异一键修改；每次修改都是一个可回退的版本。
- **建模引擎随安装包自带**：第一次打开「预研 → 代码建模」时自动解到本机（约一分钟，不联网），之后常驻。模型写的代码只在沙箱里运行（不能读写文件、碰不到密钥、超时即杀）。
- **市场调研**：规划 → 检索 → 机会评分 → 审校；评分必须引用证据，IP 风险高的一票否决；一键采用为项目。
- **项目看板**：想法 → 调研 → 预览图 → 模型 → 打样 → 上架 → 运营 → 复盘，拖拽流转，跳阶段要写原因。
- **3D 模型工具**：导入 STL / GLB、度量与水密检查、缩放到尺寸、切平底并封口、镜像、导出、调起切片软件。
- **演示模式**：不填任何密钥也能把调研和代码建模完整走一遍（建模用的是内置脚本 + 真引擎）。

## 用之前

- 真实使用需要你自己的 **DeepSeek** 密钥（必填）和智谱搜索密钥（可选），在「设置 → 接口密钥」里填；密钥只保存在系统的凭据管理器里。
- 代码建模、市场调研目前在「预研」页；出图、成本定价、发布包、订单这几块还没做（路线图见仓库 `docs/06-roadmap.md`）。
- 磁盘：安装包约 200 MB；引擎解开后另占约 700 MB。

## 已知问题
