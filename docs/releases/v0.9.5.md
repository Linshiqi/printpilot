这一版两件事：**右键菜单**换成了应用自己的——浏览器那个「返回 / 刷新 / 另存为 / 检查」不再出现；**建模更快、导出的 STL 更准、也更懂打印**。都不需要新的密钥。

| 系统 | 文件 |
|------|------|
| Windows 10 / 11（64 位） | `PrintPilot_0.9.5_windows_x64-setup.exe` |

`SHA256SUMS.txt` 是三个文件的校验值。安装包还没有做代码签名：Windows 上 SmartScreen 提示「未知发布者」时点「更多信息 → 仍要运行」；macOS 上第一次要在「访达」里右键应用 →「打开」（macOS 15 起在「系统设置 → 隐私与安全性」里点「仍要打开」）。

从旧版升级：直接装新的安装包即可。数据库没有变化（仍是 v5）；建模引擎的版本没变，不会重新解一遍。

## 新增：右键菜单

以前在应用里任何位置点右键，出来的都是浏览器自带的菜单——其中「刷新」会把整个界面的状态冲掉。现在按你点的位置给菜单：

- **输入框**：剪切 / 复制 / 粘贴 / 全选。
- **图片**（任何地方的图：参考图、画板里的图、对话里的图、项目里的图）：**复制图片**——复制的是图片本身，可以直接粘贴进微信、小红书网页版、PPT；以及「用默认程序打开」。
- **选中了一段文字**：复制。
- **看板卡片**：打开项目 / 进入下一阶段（清单没完成时照样会问原因）/ 做调研 / 出预览图 / 开始建模 / 打样与定价。
- **建模**：设计列表（打开 / 重命名 / 复制名称 / 删除）；3D 视图（**复位视角** / 棱线 / 成型范围 / 显示代码 / 导出 STEP · STL · 3MF / 用切片软件打开）；版本（切到这一版 / 复制代码）；对话消息（复制这段话 / 切到它产生的那一版 / 载入没改成的代码）；参考图（移除）。
- **图片**：画板列表（打开 / 重命名 / 删除）；每一张图——胶片条、中间的大图、对话里的图（设为当前 / 采用 / 送去建模 / 导出 / 复制图片 / 复制提示词 / 从画板上拿掉）。
- **调研**的历史、**定价**页的项目、打样记录（复制原因和备注 / 删除）、打印机和耗材档案（编辑 / 删除）。

几条规矩：

- 菜单里只有界面上本来就有的操作，它是捷径，不是另一套功能。
- **右键哪个就操作哪个，不用先选中它**。打开着甲设计、右键乙设计点「删除」，删的就是乙——确认框里会写明名字；右键一张不是「当前这张」的图，可以直接采用、导出、拿掉。
- 现在做不了的操作是灰的，而不是消失；删除类的操作照样要确认。
- 3D 视图里按着右键拖动（平移视角）之后不会弹菜单。
- 菜单开着时可以用 ↑ ↓ 回车 Esc；在别处再点一次右键，会直接换成那里的菜单。

## 建模：更快

给建模引擎逐段计时之后发现，时间并不花在「建模」上，而是花在量尺寸和导出上：

| 零件（一次完整的重建：执行 + 量测 + 导出 STEP 和 STL） | 0.9.4 | 0.9.5 |
|------|------|------|
| 带圆角的托盘 | 287 ms | **87 ms** |
| 旋钮（圆角 + 12 道防滑槽） | 352 ms | 259 ms |
| 165 个孔的板 | 2.7 s | 1.6 s |

- 点了「停止」、或者脚本超时之后，下一次建模不用再等几秒钟的引擎启动：新的引擎进程在后台就起好了。
- AI 写出来的代码更快：提示词现在禁止「在循环里一个个做布尔运算」（165 个孔：4.4 秒，一次减一批只要 0.2 秒，结果完全一样）；真的超时了，也会直接把这个原因告诉 AI。

## 建模：导出的 STL 更准

以前导出 STL 用的是「相对」精度：大的曲面会被分得很粗——一个 60 mm 高的放样花瓶只有 3,800 个三角面，弦差约 0.6 mm，打出来看得见棱。现在是**绝对弦差 0.02 mm**（远高于 FDM 的精度）：同一个花瓶 24,340 个面。孔很多的零件反而更小、更快（165 个孔的板 84k → 43k 个面）。代价是这类自由曲面零件的重建慢了一些（75 → 456 ms），换来的是能直接打的网格。

## 建模：更懂打印

- 指标卡多了**贴床面积**，以及三种提醒：**没有平的底面**（球、躺着的圆柱——直接打不了）；**贴床面积太小**（细腿、尖脚——建议切片时加裙边）；有多少**朝下的悬空平面**（短的可以搭桥，长的要加支撑）。
- 按规格**首次生成**时，「没有平的底面」会被当成问题让 AI 自己改掉；对话修改时不拦——你说要一个球，就给你一个球，只是提醒一句。
- AI 写的代码跑不通时，除了原始报错，还会附上一句「这种错通常怎么修」（13 种常见失败）。比如「选择器什么都没选中」，原始报错只有一句 `list index out of range`，AI 光看这句只能猜。目的是少修一轮、少花一次调用。

## 变化

- 手动「运行代码」和改参数的重建现在也能中途**停止**：以前手写的代码里有个死循环，只能干等 90 秒超时。
- 删除设计 / 画板的确认框里写明了名字。
- 从菜单点「重命名」时，名字输入框会自动拿到焦点并全选。
- 「贴床」的判断容差从 0.01 放宽到 0.05 mm：底部是曲面的零件，最低点会被量高最多 0.02 mm，以前会被误判成「悬空」、白白多问一轮 AI。
- 仓库首页的说明（README）改为英文，另有中文版；名称改为「3D 打印项目管理平台」。

## 已知问题

- 3D 视图里「右键拖动之后不弹菜单」在 macOS 上是按规范实现的，还没有在真机上验证过。
- 右键菜单没有子菜单；把设计 / 画板关联到项目仍然用工具栏上的下拉框。
- 可打印性的提醒只看平面：曲面的悬垂（比如球的下半部分）不算在「悬空平面」里。
- 真实的 AI 接口（DeepSeek、MiniMax、通义千问）仍未用密钥实测过。
- 没有自动更新，新版本需要重新下载安装包。
