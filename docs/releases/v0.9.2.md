这一版新增**图片工作台**：侧栏多了一个一级入口「图片」，接图片生成模型出图，并且和建模一样，可以**和 AI 持续对话**着改图。出好的图一键送去建模。

## 下载哪个

| 系统 | 文件 |
|------|------|
| Windows 10 / 11（64 位） | `PrintPilot_0.9.2_windows_x64-setup.exe` |
| macOS 11+，Apple 芯片（M1 及以后） | `PrintPilot_0.9.2_macos_apple-silicon.dmg` |
| macOS 11+，Intel | `PrintPilot_0.9.2_macos_intel.dmg` |

`SHA256SUMS.txt` 是三个文件的校验值。安装包还没有做代码签名：Windows 上 SmartScreen 提示「未知发布者」时点「更多信息 → 仍要运行」；macOS 上第一次要在「访达」里右键应用 →「打开」（macOS 15 起在「系统设置 → 隐私与安全性」里点「仍要打开」）。

从 0.9.0 / 0.9.1 升级：直接装新的安装包即可，资料库原地升级（数据库 v3 → v4，只新增表）；建模引擎的版本没变，**不会**重新解一遍。

## 新增

- **侧栏一级入口「图片」**。核心概念是**画板**：一个主题的一组图 = 参考图 + 和 AI 的对话 + 这条线上出过的每一张图。画板列表有封面和张数；可以重命名、关联到项目、删除。
- **和 AI 持续对话着出图、改图**：
  - 第一句话出图（「一个三槽的桌面线缆夹，哑光蓝色，白底」）。**不用自己写提示词**——AI 按这组图的用途写好：建模参考（白底、单个物体、3/4 视角、形体清楚）· 场景图 · 封面（竖构图、上方留标题位）· 自由。用的提示词在每条消息里可以展开看。
  - 之后每句话由 AI 自己判断：是**改当前这张**（「背景换成木桌面」「颜色改成橙色」——主体保持不变）、**重新出一批**（「再来几张」）、还是只是**回答问题**（「这张能当封面吗」，不出图、不花出图的钱）。
  - **点哪张，哪张就是「当前这张」**，接下来说的话改的就是它；选一张旧图再说话，就是从它另起一支。改图永远产生新图，原图留着；胶片条上看得到哪张是改出来的、哪张已采用。
  - 可以贴参考图（入库前会缩小并去掉照片里的位置信息）；可以选画幅（1:1 / 3:4 / 4:3 / 9:16 / 16:9）和一次几张。
  - 出图时分三步显示进度：正在想怎么画 → 哪一家正在出图（几张）→ 正在保存。失败时什么都不入库，输入框里的话原样留着，改好设置再发一次。
- **接了两家图片模型**（密钥在「设置 → 接口密钥」里填，只保存在系统的凭据管理器里）：
  - **MiniMax `image-01`**：文生图，约 ¥0.03 一张；不能按指令改图。
  - **通义千问图像 `qwen-image-2.0`**（阿里云百炼）：文生图 + **按指令改图**，约 ¥0.2 一张。
  - 两家都配了：生成用便宜的（可在设置里改成优先用另一家），改图总是用能改图的那家。**只配了 MiniMax 时不会假装能改图**——「改一下」会变成「按新的描述重新生成」，AI 会在回答里说明主体会有变化；右上角也一直显示当前用的是哪家、能不能改图。
  - 两家的接入地址都可以在设置里改（MiniMax 有国内站 / 国际站；百炼给的地址可能带工作空间）。
- **去向**：采用 · **送去建模**（跳到「建模」，新设计带着这张参考图和一句现成的开场白，直接出设计规格）· 导出（文件名写 `.jpg` 而原图是 PNG 时自动转码，透明底铺白）· 从画板上拿掉（图片文件仍留在资料库里）。
- 用途选「场景图」「封面」时，工作台上常驻一句平台规则：小红书要求商品首图是实物正面图，发布时要声明 AI 生成。
- **演示模式**有一个本机「画师」：不联网、不花钱，画一张示意图；它的「改图」只换背景色、主体像素原样保留——不填密钥也能把「出图 → 改图 → 提问 → 送去建模」整条线走一遍。

## 用之前

- 出图需要**两把密钥**：一把 **DeepSeek**（每一轮都由它看图、理解你的话、写提示词，约 1~2 分钱）+ 一把出图的（MiniMax 或通义千问，想要「按指令改图」就配通义千问）。
- 设置页里出图供应商的「测试连接」会**真的出一张图、产生一张图的费用**（它们没有免费的探活接口）。
- **这两家的真实接口还没有用真密钥实测过**（适配器是按 2026-09-20/21 的官方文档写的，并有解析测试）。如果出图报错，把提示里的原文发回来。

## 已知问题

- 通义千问的默认接入地址用的是 `https://dashscope.aliyuncs.com`；如果你的百炼控制台给的是带工作空间的地址，需要在「设置 → 出图」里改一下。
- 没有蒙版 / 框选式的局部重绘，改哪里靠说。
- 还不能从模型的渲染图直接出场景图（反方向的那条线），也还没有封面叠字。
- AI 的回复不是流式的；一轮开始后不能中途取消。
- 没有自动更新，新版本需要重新下载安装包。
