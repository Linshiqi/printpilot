这一版两件事：新增**「上架」**——AI 起草笔记和商品文案、合规检查、打成发布包，你只要点最后那一下「发布」；以及**在线升级**的第一步——以后升级只下载应用本身（十几 MB），不用再下整个 232 MB 的安装包。

## 下载哪个

| 系统 | 文件 |
|------|------|
| Windows 10 / 11（64 位） | `PrintPilot_0.9.6_windows_x64-setup.exe` |
| macOS 11+，Apple 芯片（M1 及以后） | `PrintPilot_0.9.6_macos_apple-silicon.dmg` |
| macOS 11+，Intel | `PrintPilot_0.9.6_macos_intel.dmg` |

`SHA256SUMS.txt` 是各个文件的校验值。安装包还没有做代码签名：Windows 上 SmartScreen 提示「未知发布者」时点「更多信息 → 仍要运行」；macOS 上第一次要在「访达」里右键应用 →「打开」（macOS 15 起在「系统设置 → 隐私与安全性」里点「仍要打开」）。

如果这个页面上还有 `…-update.exe` / `….app.tar.gz` / `latest.json`：那是给应用内升级用的，不用手动下载。

从旧版升级：直接装新的安装包即可。资料库原地升级（数据库 v5 → v6：新增一张发布包的表，给两张草稿表加了几列；已有的数据不受影响）。建模引擎的版本没变，不会重新解一遍。

## 新增：上架

侧栏顺序现在是 调研 → 图片 → 建模 → 定价 → **上架**。左边选项目，中间写，右边检查和打包。

- **笔记**：选几个**角度**（痛点 / 场景 / 过程 / 设计幕后 / 定制故事），点「AI 起草」，每个角度出一篇。同一个单品用不同角度各发一篇，是最便宜的测款方式。也可以新建空白的自己写。
- **商品**：标题、卖点、详情也可以让 AI 起草；售价默认带入你在「定价」里定的价；还有预售天数和**模型来源**（原创 / 已购商用授权 / 非商用——非商用授权的模型不能卖，会被拦住）。
- **品牌语气**（右上角）：写一次，对所有项目生效。留空 = 简洁、真诚、不夸张。
- **配图**：导入**实拍图**（自动摆正、去掉照片里的 GPS 信息），或者用这个项目在「图片」里出的图——AI 生成的图带着标记。顺序就是发布时的顺序，第一张是封面。
- **合规检查，边打字边出**：
  - 硬项（不改掉不能出发布包）：字数和图片数量超了小红书的规格；极限词（最好、第一、顶级、全网…）；功效和医疗宣称；品牌、角色、游戏影视的名字；微信号、链接、手机号这类站外导流；好评返现；商品首图不是实拍图；没填售价；没选模型来源。
  - 提醒（不拦）：用了 AI 生成的图——发布时要勾选平台的「AI 内容声明」；售价低于单位成本；提到了儿童用品、带电、接触食品、刀具造型这几类有额外要求的东西。
  - 确实要跳过硬项的话，写一句原因——它会和这个发布包一起留档。
  - 「第一步」「最后」这类说法不会被误判成极限词。
- **发布包**：处理好的图（统一成 1080 × 1440，可选「裁切填满」或「留白适应」）+ 标题 / 正文 / 话题，落在资料库的一个文件夹里。出过的包都留着。
  - **方式 A · 在电脑上发布**：打开素材文件夹、打开小红书官方的发布页，然后按「标题 → 正文 → 话题」逐项复制——复制完一项，下一项会高亮。
  - **方式 B · 用手机发布**：点「显示二维码」，用手机扫（要和电脑在同一个 Wi-Fi 下）。打开的是一个只有你能看到的临时页面：三个大按钮复制文案，图片长按保存到相册。第一次用时 Windows 防火墙会问一次，选「允许」。离开这一页它就停了。
- **回填链接**：发完把笔记 / 商品的链接贴回来。项目的「上架」阶段从此有清单（出过发布包 + 回填了链接）；两样都有了，停在「上架」的项目会自动进入「运营」。

**为什么没有「一键发布」**：小红书没有发布接口，用托管工具或脚本发布的账号会被封（2026-03 官方公告）。所以应用只负责起草和打包，点「发布」的永远是你自己。

## 新增：在线升级（第一步）

- 「设置 → 软件更新」：检查更新、看更新说明、下载并安装（有进度，装完自动重启）。应用启动后也会悄悄查一次，有新版本才提示。
- **升级只下载应用本身（十几 MB）**。建模引擎有自己的版本号、解在你的电脑上，应用升级不动它；只有哪一版真的换了引擎，才需要单独下载一次引擎（会先问你）。
- 这一版是「装上了升级的能力」：**从 0.9.6 升到以后的版本**才用得上它。而且要等发布方把更新地址配置好——在那之前，点「检查更新」只会提示「检查更新失败」，其它功能不受影响。
