# ADR-0007 · 成本定价器：算钱的公式是前后端共用的纯函数，失败的打印要摊进机时

- 状态：**已采纳**（2026-09-21，M4 开工）
- 前置：[ADR-0006](0006-project-spine.md)（项目是主线；「打样」阶段的清单等的就是这个）
- 影响：[01-prd.md](../01-prd.md) M4、[02-ux-flows.md](../02-ux-flows.md) §3.6、[03-architecture.md](../03-architecture.md) §9、[05-growth-cro.md](../05-growth-cro.md) §7

## 背景

个人卖家定价最常见的两种错：只算耗材钱（忘了机器折旧、自己的时间、失败的那几次），以及照着同行的低价定（忘了自己的产能走不了薄利多销）。M4 要让每个单品在上架之前就回答三个问题：**卖多少钱、赚多少、一天最多接多少单**。

## 决定

1. **算钱的公式全在 `pp_common::cost`，纯函数，前后端共用**。前端改任何一个格子都在本地即时重算（PRD 的验收项「改任一参数，售价与毛利即时重算」），不走后端；后端只做存取，保存时按同一套公式算出单位成本、冗余存一份给列表和项目中枢用。金额在公式和界面里是「元」的小数，落库时才换成整数「分」。
2. **成本公式**（和 PRD 最初写的有一处不同，见第 3 条）：

```
材料   = 克数 × (1 + 损耗率) × 耗材单价 ÷ 一次成功率
机时   = 打印小时 ÷ 一次成功率 × (平均功率 kW × 电价 + 机器购入价 ÷ 预期寿命小时)
人工   = (后处理 + 打包 分钟) × 人工分钟单价
单位成本 = 材料 + 机时 + 人工 + 包装 + 运费补贴

建议售价   = 单位成本 ÷ (1 − 平台费率 − 目标毛利率)  →  只往上取到尾数价
毛利率     = (售价 × (1 − 平台费率) − 单位成本) ÷ 售价
每机时毛利 = 每件毛利 ÷ (打印小时 ÷ 一次成功率)
```

3. **一次成功率同时摊到材料和机时上**。PRD 原来只摊了材料。但一次失败的打印浪费的不只是耗材——机器同样被占着、电同样在耗；对「每机时毛利」这个数尤其要紧：机器是个人卖家的瓶颈，失败率高的单品实际占用的机时比看上去多。人工不摊（人工只花在打成的那一件上）。原则同别处的成本估算：**宁多勿少**。
4. **尾数价只往上取**：100 元以下落在 x5.9 / x9.9，100 元及以上落在整数的 x9。往下取会吃掉目标毛利；所以三档建议价的实际毛利率一定 ≥ 目标值。三档的目标毛利率（默认 50% / 60% / 65%）是资料库级的默认值，可以改；取完尾数撞在一起的档只留一个；费率 + 目标毛利 ≥ 100% 时那一档不出现。
5. **三条提醒，都不拦人**：毛利率不到 50%；每机时毛利低于底线（默认 ¥5 / 小时，可改）；售价落在调研到的竞品价格带之外（高于上沿 → 要有差异化撑得住；低于下沿 → 别打价格战）。亏本价单独提示。
6. **竞品价格带来自调研**：这个项目采用自哪张机会卡，就用那张卡的价格带；否则取名下调研里所有机会的范围；没调研过就如实说看不到。
7. **克数和时长有三个来源，可信度递增**：
   - 「按名下 N 个模型估算」：体积法（壳 0.84 mm + 15% 填充，和预研页网格工具同一条公式），用选中的耗材密度和打印机出料速度；名下几个零件就合计；
   - 切片软件给的数：人自己填；
   - **「用最近一次成功打样的实际值」**：一键带入。打样记录 ≥ 3 次时，还会给出记录里的实际成功率、可一键采用（次数太少不给——两次里失败一次不等于成功率 50%）。
8. **打样记录**：预估 vs. 实际（克数、时长）、成功 / 失败。**失败必须写原因**——和淘汰原因一个道理，它是改设计、调参数的依据。记这一笔时把成本模型里当时的预估一起存下，之后才看得出估得准不准。
9. **档案与默认值**：打印机（平均功率、购入价、预期寿命、出料速度、成型空间）和耗材（单价、密度）建成档案；成本模型里选一份档案 = 把它的数**带进来**，之后仍可在这个项目里单独改（模型里存的是数，不是对档案的引用——改档案不会悄悄改掉已经定好的价）。电价、人工、包装、运费补贴、损耗、成功率、渠道这些是**资料库级的默认值**，新项目的成本模型从它起步。没建任何档案也能用：有一套出厂假设（256 mm 立方、100 W、¥3000、5000 小时、28 g/h；PLA ¥70/kg）。
10. **渠道费率是预设，不是常量**：小红书 5% / 2%、闲鱼 0.6%、微信小店按 2% 起步（1%~5% 视类目），都可以直接改；界面上写明核对时间，提醒以卖家后台为准。
11. **产能**：`一天能交付的好件数 = 机器台数 × 每天开机小时 ÷ (打印小时 ÷ 成功率)`；「48 小时内最多发几件」直接对应小红书现货的发货时限——接单超过这个数就该挂预售；再给一个「机器全开时这个单品一天的毛利上限」。
12. **入口**：侧栏一级入口「定价」，排在「建模」后面（调研 → 图片 → 建模 → 定价）。左边是项目列表——成本模型是项目的东西（`cost_models.project_id` 是主键），不像画板 / 设计那样可以不挂项目。改完停手约半秒自动保存。
13. **「打样」阶段从此有清单**（ADR-0006 的下一步）：有一次成功的打样记录 + 在定价器里定了售价。项目中枢在这个阶段的按钮是「打样与定价」，并多了一栏摘要（单位成本 / 售价 / 打样成功数）。

## 数据（schema v5）

四张表 v1 就建好了（`printers`、`materials`、`print_runs`、`cost_models`），这次只补两样：`print_runs.deleted_at`（打样记录可以删，软删除）；`library_settings(key, value_json)`——资料库级的设置，现在只有一行 `cost_defaults`。

迁移上的一个教训：`ALTER TABLE … ADD COLUMN` 不是幂等的。升级到一半被打断（加了列、还没写回版本号），下次启动会再跑一遍然后报「列已存在」，库就打不开了。所以加列走 `add_column_if_missing`（先查 `pragma_table_info`），有测试模拟这种中断。

## 没有选的路

- **成本模型引用档案（存 id，算的时候现取）**：改一次电价，所有项目的成本一起变——听起来方便，但已经定好价、上了架的单品不该因为后来改了一个默认值就悄悄变了账。现在是「带入」：存数，不存引用。
- **调本机切片软件的命令行做精确估算**（PRD 的 P2）：准，但各家命令行差别大，还要处理没装的情况。先用体积法 + 实际值回填；打过一次之后实际值比任何估算都准。
- **耗材库存自动扣减、低库存提醒**（PRD 的 P1）：要先有订单和打印队列（M6）才扣得准，到那时一起做。
- **把「毛利率 ≥ 50%」做成阶段门**：PRD 的通过标准里有这一条，但它是个判断而不是事实——有的引流款就是故意定低价。做成提醒，不做成拦路的清单项。
