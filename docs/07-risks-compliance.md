## 2. 经营主体与税务（给用户的提示，需确认）

- **免登记口径**：《网络交易监督管理办法》第八条，个人年交易额累计不超过 10 万元可免于登记；**多平台、多店铺合并计算**，并须公示自我声明。
- **税务**：平台按季度向税务机关报送卖家身份与收入信息。个人卖货的增值税起征点按次计算；登记为个体工商户后可适用小规模纳税人的月销售额免征政策（具体以主管税务机关为准）。
- **产品内落点**：数据页累计全渠道年度销售额，接近 8 万元时提示「考虑办理个体工商户」——这同时解锁微信小店 API 渠道。

## 3. 上架前合规检查清单（做进 Lint）

| 检查项 | 类型 | 不通过时 |
|--------|------|----------|
| 标题 / 正文 / 话题字数，图片比例与数量符合渠道规格 | 自动 | 阻断 |
| 极限词（最、第一、顶级…）与功效 / 医疗宣称 | 自动 | 阻断（可强制跳过并记录） |
| IP 名词（角色、品牌、影视游戏名）命中词库或被模型判为高风险 | 自动 + 人工 | 阻断 |
| 模型来源许可证：原创 / AI 生成（付费档）/ 已购商用授权 / **非商用（禁止）** | 人工选择 | 非商用阻断 |
| 商品首图为实拍，不是 AI 生成图 | 自动（看资产标记） | 阻断 |

| 品类预警：儿童玩具、灯具 / 带电、食品接触、刀具类造型 | 自动（关键词）+ 人工 | 提醒 |

## 4. 作为软件发行方的合规（公开分发前处理）

| 事项 | 现状判断 | 动作 |
|------|----------|------|
| AIGC 标识义务 | 《标识办法》对「提供生成合成服务」的一方有显式 + 隐式标识、用户协议说明、留存日志 ≥ 6 个月等要求。BYOK 的本地工具是否属于「服务提供者」存在解释空间 | 按**从严**实现：默认叠加显式标识、写隐式元数据、本地保留生成日志；用户协议写明用户的声明义务。**需确认** |
| 生成式 AI 服务登记 / 备案 | 仅调用已备案模型 API 的应用，通行做法是向属地网信办登记；纯 BYOK 本地工具的适用性不确定；一旦提供**官方中转额度**，我们就是明确的服务提供者 | MVP 保持 BYOK；做中转之前先完成登记评估。**需确认** |
| 官网与下载 | 面向国内用户的网站需 ICP 备案 | 沿用发行主体现有资质 |
| 隐私政策 | 应用本地处理数据，但会把用户输入发往其配置的第三方接口 | 首次启动展示：哪些数据发往哪些第三方、不上传到我们的服务器；遥测默认关闭 |
| 第三方条款 | 各供应商对输出的权属与商用约定不同（Tripo 免费档产出归平台、Meshy 免费档为 CC BY 4.0、混元未找到权属条款） | 设置页每个供应商旁显示「商用提示」；默认预设只选付费即可商用的方案 |
| 开源许可证 | 几何 / 图像依赖只用 MIT / Apache / BSD / MPL；字体用 OFL | 依赖许可证检查纳入发布流程；「关于」页列出第三方声明 |

## 5. 明确不做的事

1. 不做自动发布、定时代发、自动评论 / 私信 / 点赞，不集成浏览器自动化或逆向接口。
2. 不抓取小红书、MakerWorld、Printables 等明确禁止抓取的平台。
3. 不帮用户生成或上架受版权保护的角色、品牌衍生品。
4. 不提供批量模板化的 AI 换景。
5. 不生成好评返现、刷单相关的话术与物料。
6. 不把买家个人信息发给任何模型。
